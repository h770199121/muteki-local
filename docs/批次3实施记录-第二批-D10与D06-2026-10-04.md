### 5.3 遗留 — 证据链接（eval_verdict）

新增第三道门：gate 接受的每个 flag 值必须**回查到至少一条含该 flag 的真实 `tool.result` 输出**（`tool.start` 是命令输入、`text.delta` 是散文，均不作证据）；找不到则 `gate_accepted` 降级并记入 `unlinked_flags`，找到则记 `evidence_links`（flag → tool.result seq 列表）。修复"接受事件只证明一个决定、不证明一次执行"的缺口。外部判定路径不受影响。

### 5.4 遗留 — 归约按事件顺序消歧（usage_reduce）

batch 1 的纯总量比较升级为 **seq 感知**：
- rollup 与 solver 合计相等 → 完整（两视图一致）；
- rollup 是**更新**快照（max seq 更大）且更大 → 超集（challenge-scope 独有调用）→ **切 basis=challenge_rollup、complete=True**，rollup 成为权威总量；
- rollup 更新但更小 → 账目不一致，显式披露（SMALLER）；
- rollup **过期**（seq 更旧）且不等 → 不完整（STALE），命名哪一侧滞后。

回应审计"仅翻转比较符号无法解决混合时间线"——顺序比较才是区分"过期 rollup"与"超集 rollup"的依据。

### 5.7/D06 — 技能投影可见性（worker_skills.py）

`stage_extra_skills` 不再静默：每次投影向 Worker cwd 写 `skills-projection.json`——
- 每条目状态 `copied / pre_existing / failed / source_unavailable` + **per-file SHA-256**（区分"当前技能/旧副本/从未送达"并为未来 D06 刷新提供"系统生成且未被用户修改"的证明基础）；
- 复制失败记 `failures` + stderr 警告（不阻断启动——extra skills 仍是 operator convenience）；
- 预置同名 FILE 属"操作员内容保留"（pre_existing），不算失败。

### D10 — 统一 Schema 重放工具（新 `labs/nyu-ctf/replay_eval.py`）

把归档 run 从原始事件流重放成当前判据的统一 Schema（reduce v2 + 证据判定 + gate 路由 + 重放时间戳与 reducer 版本），`--only` 按前缀过滤，不改写任何归档。已执行：**26 场**（含 5 场 bootstrap 故障）→ `labs/nyu-ctf/results-eval-v3.jsonl`。统计与 v2 一致：Signal 7/12（有效 7/7）、Swift 4/7、Bonsai 4/7；token 口径为 solver 台账（Signal 2.53M / Swift 1.79M / Bonsai 1.41M）。
