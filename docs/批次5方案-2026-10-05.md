## 二、批次 5 方案（确认稿）

### 5-1 D05 重启恢复（主项）——两种路线，待用户选型

- **A 最小版（推荐）**：web-api 启动时扫描"有 run.started 无 run.finished"的 run → 标记 `interrupted`（终态+原因入事件流）→ UI 出现"继续解题"按钮 → 点击走已有 standby/resume 通路（winner continuation 或 fresh+黑板）。不自动重跑，避免重启后盲目烧 GPU。
